Define the backdoor criterion

Choosing variables

Real world datasets have dozens or hundreds of variables.

How do you choose which ones to include in your model?

Spoiler: “all of them” is not the answer.

Purpose of regression

Inference

Estimate how \(y\) responds to \(x\). You care about the coefficients.

How much does soil Pb decline with each mile from Exide?

Prediction

Estimate \(y\) for new observations. You care about the fitted values.

What’s the soil Pb at a property we haven’t sampled?

In this class (and EDS 241): focus on inference

In EDS 232: focus on prediction

If you care about inference

Then you need a strategy for choosing variables to include in, or exclude from, your model.

The wrong choice gives you a biased coefficient, even with infinite data.

Remember Simpson’s paradox?

Leaving out Region reversed the effect of temperature on bleaching.

Region is a confounder. Leaving out a confounder biases your estimated effect.

The backdoor criterion

More generally, we want to choose variables that satisfy the backdoor criterion.

A backdoor path is a path from \(x\) to \(y\) that starts with an arrow into \(x\).

A set of variables satisfies the backdoor criterion if adjusting for them:

  1. Closes every backdoor path between \(x\) and \(y\), and
  2. Doesn’t include any variables caused by \(x\)

Then the coefficient on \(x\) is an unbiased estimate of its causal effect on \(y\).

Step 1: make a DAG

Question: how does Pesticide use affect Bee abundance on farms?

  • Bigger farms use more pesticide and have fewer bees
  • Pesticide kills wildflowers, which bees feed on
  • Pesticide and bees both increase crop yield

Step 2: list the paths

Write out every path from Pesticide to Bees, including arrow direction.

  1. Pesticide → Bees
  2. Pesticide → Wildflowers → Bees
  3. Pesticide ← Farm size → Bees
  4. Pesticide → Crop yield ← Bees

Paths 1 and 2 are causal (arrows all point toward Bees). Paths 3 and 4 are non-causal.

Step 3: identify the open back doors

Path 3 (Pesticide ← Farm size → Bees) starts with an arrow into Pesticide. It’s an open backdoor.

Path 4 (Pesticide → Crop yield ← Bees) runs into a collider (two arrows point into Crop yield). It’s closed.

Step 4: adjust appropriately

Close open backdoors by including variables.

  • Include Farm size

Leave closed paths closed by excluding variables.

  • Exclude Crop yield

And Wildflowers? It’s on a causal path. Include it or not, depending on your question (more on that soon).

\[ \text{Bees} = \beta_0 + \beta_1 \text{Pesticide} + \beta_2 \text{Farm size} + \epsilon \]

Identify confounders, colliders, and mediators in DAGs

Confounders, colliders, and mediators

Confounder

Causes \(x\) and \(y\)

Collider

Caused by \(x\) and \(y\)

Mediator

Caused by \(x\), causes \(y\)

Confounders

Peak SST ← Region → Percent bleached is an open backdoor.

Region’s effect on bleaching leaks into the Peak SST coefficient.

Close it by including Region in the model.

Confounders: with and without

Colliders

Why do restaurants in popular locations seem to have worse food?

Location and Food quality are independent. Either one can make a restaurant successful.

Location → Success ← Food quality is closed: Success is a collider.

Leave it closed by excluding Success from the model.

Colliders: with and without

A restaurant can succeed by being in a popular location OR having good food OR both. Adjusting for a collider (success) opens the path and creates a negative relationship between location and food quality that isn’t there.

Mediators

Distance from Exide affects children’s blood Pb through soil Pb.

There’s no backdoor: no arrows point into Distance.

So it’s not about bias. It’s about which question you’re asking.

Mediators: with and without

Total vs direct effects

Exclude the mediator

The total effect of distance: everything that changes when you move farther from Exide.

Include the mediator

The direct effect of distance: what changes when you move farther but hold soil Pb constant.

Here the direct effect is ~0. Distance only matters because of soil Pb. Neither model is biased, they answer different questions!

Recap

  • Confounders open backdoor paths that must be blocked. Include them.
  • Colliders close paths. Leave them alone. Exclude them.
  • Mediators need careful thought. Include them for the direct effect, exclude them for the total effect.

Simulate biased and unbiased inferences

Simulate blocking an open back door

Farm size is a confounder.

Pesticide ← Farm size → Bees is an open backdoor.

True effect of pesticide: -3 bees per kg/ha

Simulate data according to the DAG

Simulate causes before effects. Follow the arrows!

set.seed(1)
n <- 300
confound <- tibble(
  farm_size = rnorm(n, mean = 100, sd = 30),
  pesticide = rnorm(n, mean = 2 + 0.05 * farm_size, sd = 1),
  bees = rnorm(n, mean = 60 - 3 * pesticide - 0.2 * farm_size, sd = 5)
)
confound_lm <- lm(bees ~ pesticide, confound)
confound_adj_lm <- lm(bees ~ pesticide + farm_size, confound)

Adjusting closes the back door

  • Without farm size: -5.44. Biased: overestimates the harm.
  • With farm size: -2.79. Unbiased.

Simulate opening a blocked back door

Crop yield is a collider.

Pesticide → Crop yield ← Bees is closed.

True effect of pesticide: -3 bees per kg/ha

Simulate data according to the DAG

collide <- tibble(
  pesticide = rnorm(n, mean = 7, sd = 1.5),
  bees = rnorm(n, mean = 60 - 3 * pesticide, sd = 5),
  crop_yield = rnorm(n, mean = 2 + 1 * pesticide + 0.2 * bees, sd = 0.5)
)
collide_lm <- lm(bees ~ pesticide, collide)
collide_adj_lm <- lm(bees ~ pesticide + crop_yield, collide)

Adjusting opens the closed path

  • Without crop yield: -2.76. Unbiased.
  • With crop yield: -4.53. Biased: for a given yield, more pesticide means fewer bees.

Simulate adjusting for a mediator

Wildflowers is a mediator. There’s no backdoor.

Direct effect of pesticide: -1 bee per kg/ha

Indirect effect, through wildflowers: \(-4 \times 0.5 = -2\)

Total effect: \(-1 + -2 =\) -3 bees per kg/ha

Simulate data according to the DAG

mediate <- tibble(
  pesticide = rnorm(n, mean = 7, sd = 1.5),
  wildflowers = rnorm(n, mean = 50 - 4 * pesticide, sd = 5),
  bees = rnorm(n, mean = 30 - 1 * pesticide + 0.5 * wildflowers, sd = 3)
)
mediate_lm <- lm(bees ~ pesticide, mediate)
mediate_adj_lm <- lm(bees ~ pesticide + wildflowers, mediate)

Adjusting changes the question

  • Without wildflowers: -2.95. The total effect.
  • With wildflowers: -0.76. The direct effect.

Recap

Choosing variables for inference

Goal: choose variables for your model that avoid bias.

  1. Before you write any code, make a DAG that describes what you think the causal relationships are
  2. List the paths and identify the backdoors
  3. Close the open ones (confounders) and leave the closed ones alone (colliders)
  4. Decide whether you want the total or direct effect (mediators)
