Turn to a neighbor. For the ag_pct coefficient:

  1. What are \(H_0\) and \(H_A\)? What’s the p-value?
  2. Do we reject \(H_0\)?
  3. Interpret the 95% confidence interval in a sentence.

Interpretations

  • \(H_0: \beta_1 = 0\), \(H_A: \beta_1 \ne 0\). The p-value is 0.024.
  • If farmland had no effect on nitrate, a slope at least as far from 0 as 0.037 would be unlikely (p < 0.05). Reject \(H_0\).
  • We are 95% confident that nitrate increases by between 0.005 and 0.069 mg/L for each additional percentage point of farmland.

True or false?

  1. The p-value is the probability that \(H_0\) is true.
    • False. It’s the probability of a statistic at least this extreme if \(H_0\) were true.
  2. If we repeated the study many times, about 95% of our 95% confidence intervals would contain \(\beta_1\).
    • True. “95% confident” describes the method, not this one interval.
  3. A small p-value means farmland causes higher nitrate.
    • False. That’s what the rest of today is about.

Precise \(\ne\) unbiased

A small p-value and a narrow confidence interval mean \(\hat \beta_1\) is precise.

They don’t mean it’s unbiased.

If our model leaves out a confounder, or includes a collider, then \(\hat \beta_1\) is precisely estimating the wrong thing. More data makes the interval narrower around the wrong value.

Review: causal inference

DAG vocabulary

Directed Acyclic Graph: your theory of what causes what.

  • Nodes: variables (measured or not!)
  • Arrows: direct causal effects
  • Path: any route from \(x\) to \(y\) along arrows
  • Causal path: every arrow points toward \(y\)
  • Backdoor path: starts with an arrow into \(x\)

Open and closed paths

A path is open if association can flow along it. Each variable on a path either passes it along or blocks it.

Middle variable Shape Not in model In model
Mediator \(x \rightarrow m \rightarrow y\) Open Closed
Confounder \(x \leftarrow c \rightarrow y\) Open Closed
Collider \(x \rightarrow k \leftarrow y\) Closed Open

Colliders are the odd one out: adjusting for them opens a path.

The backdoor criterion

A set of variables satisfies the backdoor criterion if adjusting for them:

  1. Closes every backdoor path between \(x\) and \(y\), and
  2. Doesn’t include any variables caused by \(x\)

Then the coefficient on \(x\) is an unbiased estimate of its causal effect on \(y\).

Confounders, colliders, and mediators

Confounder

Causes \(x\) and \(y\)

Include it

Collider

Caused by \(x\) and \(y\)

Exclude it

Mediator

Caused by \(x\), causes \(y\)

It depends: total or direct effect?

Practice: farmland and nitrate

Question: how does Farmland affect groundwater Nitrate?

  • Flat valley floors (Topography) are easier to farm, and have shallow water tables that collect nitrate
  • Farms apply Fertilizer, which leaches into groundwater
  • Runoff from farms and nitrate-rich groundwater both feed Algal blooms in nearby streams

With a neighbor: list every path from Farmland to Nitrate. Which are backdoors? Which are open?

Practice: paths

  1. Farmland → Nitrate (causal)
  2. Farmland → Fertilizer → Nitrate (causal)
  3. Farmland ← Topography → Nitrate (open backdoor)
  4. Farmland → Algal blooms ← Nitrate (non-causal, closed: collider)

Practice: adjustment

  • Topography is a confounder. Include it to close path 3.
  • Algal blooms is a collider. Exclude it to keep path 4 closed.
  • Fertilizer is a mediator. Exclude it for the total effect of farmland, include it for the direct effect.

For the total effect:

\[ \text{Nitrate} = \beta_0 + \beta_1 \text{Farmland} + \beta_2 \text{Topography} + \epsilon \]

Handout

Confounders, colliders, and mediators

Three case studies. Each features one of a confounder, a collider, or a mediator. For each one:

  1. Paths: write out every path from \(x\) to \(y\)
  2. Backdoors: which are backdoors? Open or closed?
  3. Adjustment: which variables do you include or exclude?
  4. Estimates: draw each model’s coefficient and 95% CI
  5. Verdict: which model is biased? (Or: which is total, which is direct?)

Debrief

  • Which case study had the confounder? The collider? The mediator?
  • In which case did the biased model get the sign wrong?
  • Could you tell which model was biased from summary() alone? Why not?
  • For the mediator: which effect would a utility designing a rebate program care about?

Recap

Choosing variables for inference

  • Small p-values and narrow confidence intervals mean precise, not unbiased
  • Make a DAG before you fit a model, including variables you can’t measure
  • Close open backdoors (confounders), leave closed paths closed (colliders)
  • Decide whether you want the total or direct effect (mediators)
  • If you can’t close a backdoor, say so: it’s a limitation of your analysis
