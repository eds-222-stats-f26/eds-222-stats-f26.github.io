Overview

In lab 7, you modeled whether a public water system had a health-based Safe Drinking Water Act violation. Today you’ll model how many violations it had. The health column counts them.

  • pwsid: public water system ID
  • pctpov: percent of households below the poverty line
  • health: number of health-based SDWA violations that year

Same recipe as lab 7: visualize, fit, predict. Only the family and the link change.

# The CSV file is in /courses/EDS222/data
drinking_water <- read_csv(____) |>
  select(pwsid, pctpov, health)

With a count response, the raw data are hard to read, so we’ll bin pctpov again and calculate the mean number of violations in each bin.

pov_summary <- drinking_water |>
  mutate(
    pctpov_bin = cut(
      pctpov,
      breaks = seq(0, 100, by = 10),
      include.lowest = TRUE
    )
  ) |>
  summarize(
    pctpov = mean(pctpov),
    mean_health = ____,
    var_health = var(health), # we'll use this in Part 2
    n = n(),
    .by = pctpov_bin
  )

ggplot(pov_summary, aes(x = pctpov, y = mean_health)) +
  geom_point(aes(size = n), color = "cornflowerblue") +
  labs(x = "% below poverty", y = "Mean violations")

Fit

Our model in statistical notation is:

\[ \begin{aligned} \text{Violations} &\sim \text{Poisson}(\lambda) \\ \log(\lambda) &= \beta_0 + \beta_1 \text{PctPov} \end{aligned} \]

Part 2: Check the Poisson assumption

A Poisson variable’s variance equals its mean. But that’s the mean for a given value of the predictor, \(\lambda\), not the mean of the whole dataset. Systems with different poverty levels have different \(\lambda\)s, so the overall variance would mix those differences in.

Instead, use the bins from Part 1. Within a bin, poverty is roughly constant. Plot the variance in each bin against its mean, and add a line where variance = mean.

ggplot(pov_summary, aes(x = ____, y = ____)) +
  geom_point(aes(size = n)) +
  geom_abline(slope = ____, intercept = ____, linetype = "dashed") +
  labs(x = "Mean violations in bin", y = "Variance in bin")

How does the variance compare to the mean? Does the Poisson assumption hold?
